# Security and deployment limits

The included server is for one operator on a trusted computer. It listens on `127.0.0.1`, pins Host to its exact origin, rejects cross-origin requests, and requires same-origin headers for API writes. It does not implement login, per-user isolation, TLS, rate limiting, encrypted storage, encrypted exports, retention enforcement, or secure deletion. Other local users and processes with access to the listener or data directory may access the workspace. This is not a production authentication system.

The local server supplies a fixed `local-operator` principal. `lib/api.mjs` accepts a principal from a trusted server adapter and checks it against `PRINCIPAL_ID`; it never derives identity from visitor-supplied authentication headers. For a hosted service, replace the local principal adapter with verified server-side sessions/OIDC, enforce workspace membership and per-resource authorization, use HTTPS, protect storage, impose upload/rate/retention limits and audit operational logs. Never trust forwarded identity headers unless an authenticated gateway strips and supplies them. Do not expose this server as-is.

Storage has explicit content hashes, media/size limits, path validation, atomic object replacement and SQLite transactions. Hashes confirm byte identity, not the authenticity of speech or participant consent. Consent checkboxes are operator attestations, not proof that participants agreed. Transcript corrections preserve audio but replace the current text; the event table is an operational log, not a tamper-proof archive. Original media is preserved until you manage retention locally. Source text and images remain untrusted evidence and must not be interpreted as executable instructions.

IndexedDB and disk data are not encrypted by the app. Back up the entire data directory while the server and transcription worker are stopped, or use a consistent SQLite backup mechanism. Transcripts and exported source links may reveal private content. This repository ignores local data and exports should be saved elsewhere. Model output can hallucinate, particularly in silence; review it against audio before relying on it.

The local transcription adapter uses subprocesses and temporary files with cleanup. It requires an existing model path and includes no API client or billing code. Custom adapters can execute arbitrary code and access network and secrets; run only adapters you trust. The worker supplies an AbortSignal and the included adapter honors it. A custom adapter that ignores it may run beyond its lease, although stale completion is rejected. This is not a process sandbox.

Report issues using a minimal synthetic reproduction. Do not post real audio, transcripts, credentials or private links in public issues.
